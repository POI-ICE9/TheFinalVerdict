# TheFinalVerdict - Backend API

Backend Node.js/Express per la piattaforma TheFinalVerdict.

## Stack Tecnologico
- Node.js + Express
- PostgreSQL (Sequelize ORM)
- Redis (cache & sessioni)
- JWT (autenticazione)
- Socket.IO (real-time)
- Winston (logging)

## Installazione

```bash
npm install
cp .env.example .env
# Modifica .env con le tue credenziali
